# Ветеринарная клиника

Исходный код веб-приложения для управления ветеринарной клиникой.

## Возможности
- Управление владельцами животных.
- Управление питомцами.
- Запись на приём к ветеринару.
- Просмотр и изменение статусов приёмов.
- Хранение данных в браузере.
